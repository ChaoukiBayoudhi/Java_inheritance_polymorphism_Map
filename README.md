# Java inheritance polymorphism Map

A Java console application.

## Tech stack

- Java
- Lombok

## Concepts covered

Collections, console input (Scanner), inheritance, static/final members.

## Project structure

- `src`: Account, AccountStatus, Bank, CurrentAccount, Main, SavingAccount

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).

The code uses Lombok annotations: add the Lombok library and enable annotation processing in your IDE.
